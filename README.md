# Forma — фитнес-приложение для мужчин

Персональные тренировки для похудения и набора массы: зал, дом, дорога, офис, пробежка.

**Открыть приложение:** https://egabdushev-ctrl.github.io/forma-men/

## Возможности

- Анкета из 7 шагов и программа под цель, форму тела, возраст, телосложение и уровень
- Экран «Сегодня»: кольца активности, тренировка дня, быстрые тренировки, норма калорий и БЖУ
- Библиотека из 65 упражнений с техникой выполнения
- Плеер тренировки с таймером отдыха, звуком и вибрацией
- Прогресс: график веса, ИМТ, серия дней, история
- PWA: установка на телефон, тренировки без интернета
- Клуб: рейтинги, друзья, локации, совместные цели, пари на бонусные очки (нужен Supabase, см. [SETUP.md](SETUP.md))

## Устройство

Vanilla JS, HTML и CSS без сборки. Личные данные хранятся в `localStorage` на устройстве.

| Файл | Назначение |
|---|---|
| `index.html` | Всё приложение |
| `config.js` | Адрес приложения и ключи Supabase |
| `sw.js` | Service worker для офлайн-режима |
| `manifest.webmanifest` | Манифест PWA |

Для локального запуска подойдёт любой статический сервер, например `python -m http.server`.

Приложение не заменяет консультацию врача, особенно в возрасте 45+ и при хронических заболеваниях.
